# Drug Release Data Sources

## Literature Search Results

### Source 1: Nature Communications (2022)
- **Title**: Machine learning models to accelerate the design of polymeric long-acting injectables.
- **DOI**: 10.1038/s41467-022-35343-w
- **Dataset**: Published supplementary CSV dataset of PLGA micro/nanoparticle drug release.
- **Relevance**: Extremely high. Features true longitudinal time points (days/hours) mapping specific formulations to cumulative release percentages.

### Source 2: Scientific Reports (2024)
- **Title**: Machine learning integrated with in vitro experiments for study of drug release from PLGA nanoparticles.
- **DOI**: 10.1038/s41598-024-82728-6
- **Dataset**: Supplementary data covering 150+ release profiles.
- **Relevance**: High. Includes temporal drug release data tailored for ML prediction.

### Ranking
- Both are **Class B** (Experimental data available in supplementary files / published repositories).
