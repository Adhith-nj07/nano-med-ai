# Future Validation Strategy

## Mechanistic Simulation Validation

Because dynamic simulations yield time-series trajectories rather than static points, standard classification metrics (Accuracy, F1) are invalid.

### 1. Dynamic Trajectory Similarity
Future models (e.g., predicting drug release) must be validated using:
- **Time-Integrated RMSE**: The root mean square error calculated across all time points for a given trajectory.
- **Curve Shape Analysis (Similarity Factor - $f_2$)**: The FDA-recommended $f_2$ metric used to compare dissolution profiles.

### 2. Experimental Traceability
Every prediction generated by the Simulation Engine must carry metadata defining:
- Model used (e.g., `KorsmeyerPeppas_ML_Hybrid_v1`).
- Source dataset utilized for calibration.
- Boundary conditions (warning if inputs fall outside the training domain).
- Formal Uncertainty limits.
