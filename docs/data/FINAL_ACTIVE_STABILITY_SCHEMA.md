# Final Active Stability Schema

This document describes the exact schema used by the currently active predictive pipeline (`models/stability_model_final.joblib` and `src/predict.py`).

## 1. Raw User-Facing Features

These are the inputs expected by the `predict_stability()` API function:

| Feature | Description | Type |
|---|---|---|
| `Shape` | Morphological shape (e.g., Spherical, Rod) | string |
| `Core` | Metal core material (e.g., Ag, Au, TiO2) | string |
| `Size_nm` | Core diameter in nanometers | float |
| `Medium` | Measurement buffer/medium (e.g., Water, PBS pH 7.4) | string |
| `Ligand_SMILES` | Canonical SMILES string of the primary capping agent | string |

## 2. Derived Features (Generated by API)

The API internally converts the raw features into the following derived features before passing them to the Scikit-Learn `ColumnTransformer`:

| Feature | Description | Derivation Logic | Type |
|---|---|---|---|
| `Coating_Charge` | Formal electrostatic charge class | Extracted from `[O-]`, `[N+]` patterns in `Ligand_SMILES` (Anionic, Cationic, Zwitterionic, Neutral) | string (Categorical) |
| `Estimated_Ligand_MW` | Proxy for steric bulk / molecular weight | Sum of `C, O, N, S, P` atomic masses from `Ligand_SMILES` | float |
| `Log_Size` | Log-transformed core size | `np.log1p(Size_nm)` | float |

## 3. Target Variable

| Target | Unit | Note |
|---|---|---|
| Zeta Potential | mV | Used as an experimentally measurable proxy for colloidal stability. |

## 4. Metadata (Used only during validation)

| Feature | Description | Type | Role |
|---|---|---|---|
| `study_id` | Unique DOI or reference string | string | Grouping variable for `GroupKFold` |

*Note: Metadata is NOT required by the inference API, but is strictly required to reproduce the validation metrics.*
